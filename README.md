# Movie Recommendation System

This project is a Machine Learning based Movie Recommendation System.

## Dataset

The dataset contains information about movies such as:

- Movie title
- Genres
- Overview
- Release date
- Popularity
- Rating
- Vote count
- Budget
- Revenue

## Dataset File

The movie database is stored in:

`movies.csv`

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Project Objective

The objective of this project is to recommend movies to users based on
similarity between movies and their characteristics.
